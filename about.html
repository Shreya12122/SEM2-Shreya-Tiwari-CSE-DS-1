About the Project

The Inspiration & Idea

This project was conceived as a high-fidelity frontend replica of the popular e-commerce platform Myntra. Built as part of a CSE Web Development Lab assignment, the core objective was to move beyond a static mockup and create a premium, interactive client-side web application.

The design emphasizes tactile aesthetics, glassmorphism, responsive navigation menus, and smooth 3D micro-interactions. It serves as a showcase of modern CSS grid layouts combined with custom-written Vanilla JavaScript state machines.

How It Was Built

The developer, Shreya Tiwari, constructed this project utilizing pure frontend web technologies:

  • Semantic HTML5 Structure: Formulated independent documents for Home, Men's, Women's, Login, and Cart pages with clean content separation.
  • Vanilla CSS Grid & Flexbox: Refactored layouts using modern design variable configurations, responsive breakpoints, and tactile button compressions.
  • Real-time JS State Engine: Coded a lightweight state engine in pure JavaScript handling cart updates, item deletions, and layout animations.
  • 3D Hardware Acceleration: Applied perspective-based mouse tracking math to make listings tilt responsively on cursor hovers.
